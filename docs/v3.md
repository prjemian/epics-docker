# Recipe for Docker image prjemian/synapps v3

Docker image `prjemian/synapps` providing EPICS base, synApps, and Area Detector software providing IOCs (servers) for development, simulation, testing, and training.

## Goals

- Easily-deployed EPICS IOCs
  - EPICS base `softIoc` including support for its command-line options
  - synApps xxx IOC
    - as-supplied
    - with my customizations
  - area detector IOC
    - detector drivers
      - ADSimDetector
        - as-supplied
        - with my customizations
      - ADCSimDetector
      - ADURL
      - ADUVC
      - pvaDriver
      - ffmpegServer
    - plugins: all except
      - file writers: all except NeXus
  - Easy to start IOC with a custom prefix
  - Run IOCs inside a terminal multiplexer
    - use of "screen" in prjemian/synapps v2.0.1 has problems with podman
    - seek robust alternatives (not EMACS)
- display files
  - MEDM, caQtDM, ...
  - and related grphics files
  - gather all in one directory for each format
- Compilation
  - Deliver pre-built image
  - Easy to make local patches
  - full toolset to (re)compile
  - full logs of each compilation step
- minimize image size where possible
- compatible with docker and podman
- support for configuration options
  - env vars, ports, volumes, ...
- easy to run as container on various hosts
  - Linux
  - Mac
  - Windows
  - Synology
- host architectures
  - x86_64 (Intel and AMD)
  - arm for RPi (stretch goal)
  - Mac (stretch goal)
- documentation
- best practices
  - efficient multi-layered image design
    - base-os
    - base-epics
    - base-synapps
    - base-area_detector
      - each camera driver
  - reusable hierarchies
  - easy to upgrade the recipe
  - easy to maintain
  - faster deployment
